# Nightreign Boss Skills（ナイトレイン ボス制作スキル集）

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **日本語**

『ELDEN RING NIGHTREIGN（エルデンリング ナイトレイン）』のボスをオフラインMODとして作るための Claude Code スキル集です。正式に発売済みの
他タイトルからボスを移植する方法、自作モデルからオリジナルボスを作る方法、そしてそれを「夜の王」戦に仕立てる方法をまとめています。実際に
プレイされるところまで到達した移植・制作の経験から抽出し、ゲーム内で効果が確認できた手法だけを残しました。推測するよりフレーム表を読みたい人のためのノートです。

> 非公式のファンプロジェクトです。FromSoftware、バンダイナムコエンターテインメント、Anthropic とは一切関係がなく、承認も受けていません。

## スキルの内容

| スキル | 対象範囲 |
|---|---|
| `nightreign-boss-port` | ボス本体。13 段階（S0-S12）のパイプラインで進め、各段階に完了ゲートがあります：調査と抽出、オリジナルモデルのルート（リギング、バニラモーションのリターゲット）、ビヘイビアグラフのドナー、FLVER とダミー、被ダメージ判定カプセル、ルートモーションと TAE（向きの固定、旋回／再照準ウィンドウ）、開発版専用の技デバッグパネル、ダメージの担い手（ブレス、地雷、扇形）、エフェクトとサウンド（数値スロットのみ編集、GPU 負荷の予算）、プリコンパイル済み Lua AI と AI ヒープ、HP のベンチマーク、部位破壊、マルチプレイ、リリース前チェックリスト。 |
| `nightreign-nightlord-replace` | ボスを新しい夜の王、または既存の夜の王の置き換えにする：夜の王戦のイベントスクリプト、切り替えアイテム（「最後に砕いたものが有効」）、撃破記録を元の夜の王に付ける処理、全言語の名前、BGM スロット、HP 割合によるフェーズ、バニラの夜の王を基準にしたバランス（シームレス協力プレイの HP 式、4～6 人、深き夜）、マルチプレイ同期（ホストが指揮／クライアントが追従）、テストとリリースのパッケージング（ファイルの固定、レギュレーションの差分移植、インストーラー、アップグレードパッチ、プライバシースキャン）。S8-S12 を担当します。 |
| `nightreign-modding` | 他の二つが土台にする共通ベース：me3 のプロファイルと読み込み順、開発用の重ね合わせパッケージ、Smithbox と regulation.bin のセル単位の編集、WitchyBND、FLVER／TPF の差し替え、パラメータのレシピ、FXR の数値スロット編集、セルモードのビルダー、プライバシースキャン、証拠ラベル、品質基準。 |

各スキルは `SKILL.md`、必要に応じて読む `references/`、小さな補助 `scripts/` で構成されています。各記述には証拠タグ（`[game-MP]`、`[game]`、
`[code]`、`[data]`、`[sim]`、`[model]`、`[inferred]`）が付いており、ゲーム内で確認されたことと推論にすぎないことを区別できます。エンジンに関する
事実はナイトレイン 1.3.3.0（regulation 10350000）で確認したものです。ゲームのアップデート後は再確認してください。

## 絶対ルール：発売済みのゲームのみ

すべてのスキルの冒頭に必須の **Step 0** があり、ボスパイプラインの S0 段階にも組み込まれています。他タイトルのボス、キャラクター、敵、モデル、
アニメーション、エフェクト、サウンド、マップを移植する作業に入る前に、モデルは必ず次を行います：

1. Web 検索で、移植元のゲーム（またはその内容を含む DLC）が正式に一般発売され、購入できる状態であることを確認し、根拠（タイトル、発売日、
   確認した情報源）を書き残す；
2. ゲームや DLC が未発売（発表済み・開発中）の場合、素材がリーク、未発売ビルドのデータマイニング、ベータ版／ネットワークテスト（NDA の有無を問わず）
   に由来する場合、または発売状況を確認できない場合は、その移植を**拒否**し、理由を説明する。

自分のモデルや素材から作るオリジナルボスは、この確認なしで作れます。フォークや改変をする場合も、このルールは残してください。

## 必要なもの

- skills に対応した **Claude Code**、および Web 検索の有効化（Step 0 に必要）。
- PC 版 **『ELDEN RING NIGHTREIGN』**（自分で所有している正規品）と、移植元にする発売済みゲームの正規品。
- **me3**（MOD ローダー、0.10.1 以降）、**Smithbox**（パラメータ、テキスト）、**WitchyBND**（展開／再パック）。
- 作業内容に応じて：**FLVER Editor**（ナイトレイン対応のフォーク版）、**Blender** 4.x、**texconv**（DirectXTex）、**SoulsFormats** と
  .NET Framework 4.x の C# コンパイラ（小さな C# ツール用）、**Python** 3.11 以降、AI スクリプト用の **Lua 5.0.2** コンパイラ（`luac50`）、
  **DarkScript3**（イベントスクリプト）、**Seamless Co-op**（シームレス協力プレイ。マルチプレイのテスト時のみ）。

## インストール

三つのスキルフォルダをすべて Claude Code のスキルフォルダにコピーします（ボス系スキルは `nightreign-modding` を参照します）：

```
git clone <このリポジトリ> nightreign-boss-skills
cp -r nightreign-boss-skills/skills/* ~/.claude/skills/
```

- 個人スキル（すべてのプロジェクトで使用）：`~/.claude/skills/`（Windows では `%USERPROFILE%\.claude\skills\`）。
- プロジェクトスキル（特定のプロジェクトのみ）：`<あなたのプロジェクト>/.claude/skills/`。

その後、Claude Code の新しいセッションを開始してください。ナイトレインのボス、夜の王、MOD 制作について質問すると説明文に基づいて自動で読み込まれます。
名前を指定して呼び出すこともできます（「nightreign-boss-port を使っ‌​⁠‍‌​​‍‌‌​⁠​‍⁠‌​⁠​‍​⁠​​​⁠​‍​⁠‌‍​⁠​‌​⁠​‌​⁠​​​⁠‍​​‍⁠‌‌‍​‌‌‍‌​​⁠‌‍‌‍​‍​⁠‌​​⁠‍‌​⁠‌⁠​⁠‌‌て」）。
