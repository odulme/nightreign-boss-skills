# Nightreign Boss Skills（黑夜君臨 BOSS 製作技能包）

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [日本語](README.ja.md)

一組 Claude Code 技能（skills），用來以離線模組（MOD）的形式為《艾爾登法環 黑夜君臨》(ELDEN RING NIGHTREIGN) 製作 BOSS：把其他已正式發售遊戲中的
BOSS 移植過來、用自己的模型製作原創 BOSS，以及把它們做成夜王戰。內容整理自真正進入實際遊玩的移植與製作專案，只保留在遊戲中驗證有效的方法。
這些筆記寫給寧可讀幀表、也不想靠猜的人。

> 非官方粉絲專案，與 FromSoftware、萬代南夢宮（Bandai Namco）及 Anthropic 皆無關聯，亦未獲其認可。

## 技能內容

| 技能 | 涵蓋範圍 |
|---|---|
| `nightreign-boss-port` | BOSS 本體，依 13 個階段（S0-S12）的流程推進，每個階段都有出口關卡：調查與擷取、原創模型路線（綁骨、重定向原版動作）、行為圖供體、FLVER 與 dummy、受擊膠囊、根運動與 TAE（鎖定朝向、轉身／重新瞄準視窗）、僅限開發版的招式除錯面板、傷害載體（吐息、地雷、扇形）、特效與音效（只改數值欄位、顯示卡負載預算）、預先編譯的 Lua AI 與 AI 堆積、血量對標、部位破壞、連線，以及發布前檢查清單。 |
| `nightreign-nightlord-replace` | 把 BOSS 做成新夜王或替換夜王：夜王戰事件腳本、切換道具（「最後捏碎的為準」）、擊殺記給原夜王、各語言名稱、BGM 欄位、依血量比例分階段、對標原版夜王的平衡（無縫連線血量公式、4~6 人、深夜）、連線同步（房主主導／客機跟隨）、測試與發布打包（鎖定檔案、正則差量轉移、安裝程式、升級修補檔、隱私掃描）。負責 S8-S12 階段。 |
| `nightreign-modding` | 另外兩個技能共用的基礎：me3 設定檔與載入順序、分層開發疊加包、Smithbox 與 regulation.bin 儲存格修改、WitchyBND、FLVER／TPF 替換、參數配方、FXR 只改數值欄位、儲存格模式建置器、隱私掃描、證據標籤與品質驗收標準。 |

每個技能由一個 `SKILL.md`、依需要讀取的 `references/` 和幾個小型輔助 `scripts/` 組成。每項結論都附有證據標籤（`[game-MP]`、`[game]`、`[code]`、
`[data]`、`[sim]`、`[model]`、`[inferred]`），可以分辨哪些是在遊戲中親眼確認、哪些只是推論。引擎相關事實以黑夜君臨 1.3.3.0
（regulation 10350000）測得，遊戲更‌​⁠‍‌​​‍‌‌​⁠​‍⁠‌​⁠​‍​⁠​​​⁠​‍​⁠‌‍​⁠​‌​⁠​‌​⁠​​​⁠‍​​‍⁠‌‌‍​‌‌‍‌​​⁠‌‍‌‍​‍​⁠‌​​⁠‍‌​⁠‌⁠​⁠‌‌新後請重新確認。

技能正文以英文為主，描述（description）為中英雙語（兩種語言都能觸發），`nightreign-modding` 的少數參考文件為簡體中文。

文中提到但未收錄於本儲存庫的兩個配套技能：`nightreign-map-port`（競技場、地圖區塊、碰撞、導航網格）與 `ds3-nightreign-port`（黑暗靈魂 III 配方）。
沒有它們，本儲存庫的技能一樣能用，只是不涵蓋這些主題。

## 鐵則：只移植已發售的遊戲

每個技能開頭都有強制執行的**第 0 步**，並已接入 BOSS 流程的 S0 階段。在著手移植其他遊戲的 BOSS、角色、敵人、模型、動作、特效、音效或地圖之前，
模型必須：

1. 用網路搜尋確認來源遊戲（或包含該內容的 DLC）已正式公開發售、可以購買，並記下依據（名稱、發售日期、查證來源）；
2. 若遊戲或 DLC 尚未發售（已公布或開發中），或素材來自外洩、未發售版本的拆包資料、測試版／網路測試（無論是否簽有保密協議），或無法確認發售狀態，
   就必須**拒絕**這次移植並說明原因。

使用自己的模型和素材製作的原創 BOSS 不需要這項確認。若你 fork 或改編這些技能，請保留這條規則。

## 執行需求

- **Claude Code**（支援 skills），並啟用網路搜尋（第 0 步需要）。
- PC 版**《艾爾登法環 黑夜君臨》**（你自己擁有的正版），以及你要移植、已發售的來源遊戲正版。
- **me3**（模組載入器，0.10.1 或更新）、**Smithbox**（參數、文字）、**WitchyBND**（解包／打包）。
- 視任務而定：**FLVER Editor**（支援黑夜君臨的分支版本）、**Blender** 4.x、**texconv**（DirectXTex）、**SoulsFormats** 與
  .NET Framework 4.x 的 C# 編譯器（用於幾個 C# 小工具）、**Python** 3.11+、編譯 AI 腳本用的 **Lua 5.0.2** 編譯器（`luac50`）、
  **DarkScript3**（事件腳本）、**Seamless Co-op**（無縫連線，僅連線測試需要）。

## 安裝

把三個技能資料夾全部複製到 Claude Code 的技能資料夾（BOSS 相關技能會引用 `nightreign-modding`）：

```
git clone <本儲存庫網址> nightreign-boss-skills
cp -r nightreign-boss-skills/skills/* ~/.claude/skills/
```

- 個人技能（所有專案可用）：`~/.claude/skills/`（Windows 為 `%USERPROFILE%\.claude\skills\`）。
- 專案技能（僅限單一專案）：`<你的專案>/.claude/skills/`。

之後開啟新的 Claude Code 工作階段即可。詢問黑夜君臨的 BOSS、夜王或‌​⁠‍‌​​‍‌‌​⁠​‍⁠‌​⁠​‍​⁠​​​⁠​‍​⁠‌‍​⁠​‌​⁠​‌​⁠​​​⁠‍​​‍⁠‌‌‍​‌‌‍‌​​⁠‌‍‌‍​‍​⁠‌​​⁠‍‌​⁠‌⁠​⁠‌‌模組製作時，技能會依描述自動載入；也可以直接指名（「用 nightreign-boss-port」）。
