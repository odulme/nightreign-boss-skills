# 角色服装皮肤质量验收标准（通用模板）

适用对象：Blender 渲染的候选版本（vNNN_*.png）+ 网格/贴图检查脚本输出。下面的结构、权重、测试姿势、通道约定和放行条件是通用的；`<尖括号>` 里的目标值要按具体角色/服装，从参考图和参考皮肤重新量取后填入。评判者为 QA 子代理；作品负责人为最终决策者，任何版本未经其同意不得装机。

## 0. 参照基准（"满分是什么样"）
- **参考原图** `<workspace>/ref/<参考图>.png`：写下要还原的要素清单（廓形、标志、配件，以及哪些部件沿用原版件）。
- **形变基准**：同姿势下的参考皮肤（一套已在游戏里验证过的原版或成熟 MOD 皮肤）渲染 `<workspace>/work/ref_skins/<参考皮肤>_<姿势>_<机位>.png`（用 flverdump + 骨名绑定脚本从参考皮肤 FLVER 渲染）。线性蒙皮固有现象（单腿大幅摆动时裆部拉平、深蹲时臀部压平、大腿从刚性下摆穿出的台阶）以参‌​⁠‍‌​​‍‌‌​⁠​‍⁠‌​⁠​‍​⁠​​​⁠​‍​⁠‌‍​⁠​‌​⁠​‌​⁠​​​⁠‍​​‍⁠‌‌‍​‌‌‍‌​​⁠‌‍‌‍​‍​⁠‌​​⁠‍‌​⁠‌⁠​⁠‌‌考皮肤为上限，同级不扣分。
- **材质基准**：原版身体件（如 BD_M_5000）与参考皮肤的贴图通道统计（见 §5）。
- **冻结项**：负责人已经接受的体量 / 造型决定写在这里；评判者不得再以这些项扣分或提修改建议。

## 2. 拓扑与法线（A2，权重 10）
- 所有衣物网格面法线朝外（pnorm 脚本 outward ≫ inward）；裤子封闭无边界边；上衣只允许设计上的开口（下摆、袖口、领口）。
- 无孤立 / 游离面、无退化三角、无 T 形交叉；平滑着色无硬棱（平光分色图 flatcheck 中不得出现锯齿棱线）。
- 装机面集：衣物 CullBackfaces=false（双面，与原版一致）；脸部材质（及贴脸的面罩）CullBackfaces=true。
扣分：法线错误一律 −10；可见棱线每处 −3。

## 3. 蒙皮与形变（A3，权重 30）
测试姿势集（bl_render_textured pose 语法）：
- 深蹲 CR = L/R_Thigh.Y.85 + L/R_Calf.Y.-100 + Spine.Y.40，机位 side/qback/quarter/lowback/lowq
- 跨步 L_Thigh.Y.35 + R_Thigh.Y.-25，机位 side/quarter/lowback
- 分腿 L/R_Thigh.Z.12，机位 crotch
- 高踢 L_Thigh.Y.80，机位 side
- 举臂 poseZ70
规则：
- 每个顶点 ≤ 4 个骨权重，权重 < 1.5 % 必须剪掉；上衣在胸口高度以上不得含腿骨权重；下摆的大腿权重份额 ≤ 15 %。
- 任一姿势不得出现：撕裂（边长拉伸 > 2.5×）、尖刺（顶点相对邻居位移 > 1.5 cm，spike 脚本）、悬空硬‌​⁠‍‌​​‍‌‌​⁠​‍⁠‌​⁠​‍​⁠​​​⁠​‍​⁠‌‍​⁠​‌​⁠​‌​⁠​​​⁠‍​​‍⁠‌‌‍​‌‌‍‌​​⁠‌‍‌‍​‍​⁠‌​​⁠‍‌​⁠‌⁠​⁠‌‌块、裆部 V 槽、口袋脱离衣身、袖口鳍片。
- 参考皮肤同级现象不扣分；超出参考的折角 / 楔形每处 −4。

## 4. 接缝与完整性（A4，权重 20）——通常是第一优先项
- 站姿正 / 背面：上衣下摆与裤腰交界只能是一条自然下摆线，无台阶、无亮线、无"套圈"。
- 深蹲从臀后下方（lowback/lowq）与跨步后下方：平光分色图内**不得露出灰色背景**（真正的洞）；衣物内壁可见属允许（双面，暗布）。
- 腿内收 / 外展 12°：裤腰边缘不得从下摆下探出。
- 裤子向上延伸到髋关节的那一段必须存在且封口（见 SKILL.md 的坐垫 / 裆部蒙皮规则）。
扣分：任一真正的洞 −20；裤腰探出 / 台阶每处 −5。

## 5. 贴图与材质（B1，权重 10）
通道约定（由原版与参考皮肤统计得出）：
- `_a` BC1 sRGB，完整 mip；按材质写基色范围（例：黑色针织基色 11–16、织纹调制 ±3；白色标志约 232、边缘羽化 ≤ 3 px）。
- `_n` BC7：R/G 法线（G 方向沿 FromSoftware 约定）；**B = 光泽度**（金属 64–128、皮肤约 37、布料 0–30；例：黑色抓绒 B 6–18 并随织纹起伏，罗纹带 B 约 4）；A = 255。
- `_m` BC4：金属度，**布料区域必须为 0**（原版布料约 79 % 像素为 0）。
- 纹理密度：衣物区 ≥ 800 px/m；织纹周期在 2–3 m 观察距离下读作细针织而非噪点；UV 岛之间标志 / 条纹不断裂（seam guard）。
- 罗纹（下摆 / 袖口）需有法线起伏 + 边缘明暗线；缝线沿实际缝合路径。
扣分：通道语义错误（如布料 _m > 0）−6；标志跨岛断裂 −5；明显拉伸 / 接缝 −3 / 处。

## 6. 与参考原图贴合度（B2，权重 10）
逐项写位置与尺寸并量取对照（例：胸口标志‌​⁠‍‌​​‍‌‌​⁠​‍⁠‌​⁠​‍​⁠​​​⁠​‍​⁠‌‍​⁠​‌​⁠​‌​⁠​​​⁠‍​​‍⁠‌‌‍​‌‌‍‌​​⁠‌‍‌‍​‍​⁠‌​​⁠‍‌​⁠‌⁠​⁠‌‌中心高度 z 与宽度；配件位置 (x, y, z) 与宽度；口袋、兜帽、面罩的形状要素）。已冻结的造型写在 §0。

## 7. 评分与放行
- 总分 = Σ(各项得分 × 权重)/100，各项 100 分制。
- **放行条件**：总分 ≥ 90 且 A4 ≥ 90 且 A3 ≥ 85；任一"硬性一律扣分"项触发即不放行。
- 评判输出格式：每项给分 + 逐条缺陷（图名、部位、现象、量化依据、扣分）+ 最多 4 条按提分排序的修改建议（几何 / 权重 / 贴图层面，给数值）。
- 评判者不得建议负责人已排除的方向（§0 冻结项），不得以渲染高光 / 阴影深浅扣分。
